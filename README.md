# Machine Learning 2025 - Coursework

Exercises from the Machine Learning course in my B.Sc. in Computer Science at Tel-Hai.
Most models are implemented from scratch in NumPy first, then compared against scikit-learn.

## Contents

### 1. Linear regression - [`ex-1-linear-regression`](ex-1-linear-regression/src)

| Part | Dataset | Topic |
|---|---|---|
| 1 | Synthetic (Gaussian noise) | Fitting and examining a linear regression model |
| 2 | Cricket chirps | Linear regression with batch gradient descent |
| 3 | Old Faithful geyser | Mini-batch and stochastic gradient descent |
| 4-5 | House prices | Multivariable linear regression |
| 6 | Kleiber's law | Linear regression and gradient descent on a power law |
| 7 | - | Maximum likelihood estimation |
